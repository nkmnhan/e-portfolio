# E-Portfolio Theming Guide

> **Goal:** Port MediTrack's theme engine so each portfolio project can switch palettes with **one config object** — no CSS edits, no component changes.

---

## Current State

All 3 projects use **hardcoded CSS variables** in `globals.css`:

| Project | Port | Theme | Variables |
|---------|------|-------|-----------|
| **portfolio-nextjs** | 3000 | Light/Dark + Cinematic | ~40 vars (manual light/dark) |
| **artist-portfolio** | 3001 | Dark cinematic (cyan/purple) | ~15 vars (dark only) |
| **byte-folio** | 3002 | Space/cosmic (neon) | ~20 vars (dark only) |

**Problems:**
- Adding a new palette means editing `globals.css` manually
- No perceptual color scales (50–950 shades)
- No runtime switching — theme is baked into CSS
- No shared derivation engine between projects

---

## Target Architecture (from MediTrack)

```
┌──────────────────────────────────────┐
│  Component Layer                     │  bg-primary-500 text-primary-700
│  (all .tsx files)                    │  NEVER changes for theming
└──────────┬───────────────────────────┘
           │ resolves via Tailwind + cssScale()
┌──────────▼───────────────────────────┐
│  CSS Variables Layer                 │  hsl(var(--primary-50)), hsl(var(--primary-700))
│  (tailwind config + globals.css)     │  Defaults in :root/.dark, overridden at runtime
└──────────┬───────────────────────────┘
           │ values generated by
┌──────────▼───────────────────────────┐
│  Derivation Engine                   │  deriveTheme(palette) → 100+ CSS vars
│  (themeDerivation.ts)                │  Perceptual scales, hue harmonization
└──────────┬───────────────────────────┘
           │ injected by
┌──────────▼───────────────────────────┐
│  Runtime Hook                        │  <style>html.dark { --primary-50: ... }</style>
│  (use-color-theme.ts)                │  Cached, localStorage persisted
└──────────────────────────────────────┘
```

## Migration Plan

### Phase 1: Shared Theme Library

Create a shared package at the monorepo root that all 3 projects import:

```
lib/
└── theme/
    ├── color-themes.ts        # All palette definitions
    ├── themeDerivation.ts     # 5 hex → 100+ CSS vars engine
    ├── use-color-theme.ts     # Runtime <style> injection + localStorage
    ├── use-theme.ts           # Light/dark/system mode toggle
    └── ThemeSwitcher.tsx      # UI picker component
```

### Phase 3: Migrate Components to Semantic Tokens

Replace hardcoded colors with scale classes:

```tsx
// BEFORE (hardcoded)
className="bg-[var(--color-primary)] text-white"
className="text-[var(--color-text-muted)]"
className="border-[var(--color-border)]"

// AFTER (semantic scales)
className="bg-primary-500 text-primary-50"
className="text-muted-foreground"
className="border-border"
```

## How to Add a New Theme (After Migration)

### Step 1: Pick 5 Colors

| Role | What it is |
|------|-----------|
| `background` | Page canvas (darkest for dark themes) |
| `foreground` | Primary text (highest contrast) |
| `primary` | Brand / CTA (most vivid) |
| `secondary` | Supporting action |
| `accent` | Highlights / badges |

### Step 2: Add One Object

```typescript
// lib/theme/color-themes.ts
{
  id: "aurora-night",
  label: "Aurora Night",
  description: "Northern lights inspired",
  mode: "dark",
  palette: {
    background: "#0B0E17",
    foreground: "#E8ECF4",
    primary: "#00D4AA",
    secondary: "#7B61FF",
    accent: "#FF6B9D",
  },
  swatches: ["#0B0E17", "#00D4AA", "#7B61FF", "#FF6B9D", "#E8ECF4"],
}
```

### Step 3: Done

The derivation engine generates 100+ CSS variables automatically.

### Portfolio-Specific Guidelines

- **Dark themes dominate** — artwork pops against dark backgrounds
- **Neon accents OK** — unlike healthcare, portfolios benefit from vibrant glows
- **High saturation primary** — CTAs and interactive elements need punch
- **Muted backgrounds** — keep < 10% brightness to let artwork be the hero
- **Accessibility:** WCAG AA minimum (4.5:1 text, 3:1 UI elements)
